# US Pharma Commercial Ecosystem Knowledge Base

How the US pharmaceutical sector works — regulation, prescriptions, claims, distribution, pricing, commercial operations, service providers — and every major type of commercial dataset (867, DDD, Xponent, LAAD, Komodo, CRM, formulary, chargebacks) with grain and join keys. 339 concepts. Start with [Dataset Type Taxonomy](/data-assets/dataset-taxonomy.md) and [Which Dataset Answers Which Question](/data-assets/dataset-selection-guide.md).
