* [OKF Conventions Used in This Bundle](/_meta/okf-conventions.md) - How this bundle applies Google's Open Knowledge Format v0.2 and which producer extension keys it adds.
* [Relation Vocabulary](/_meta/relation-vocabulary.md) - Controlled list of predicates allowed in the `relations:` extension key.
* [Concept Type Vocabulary](/_meta/type-vocabulary.md) - The `type` values used in this bundle and what each means.
