# Provider Identifiers

NPI, DEA, ME#, HIN and vendor/master IDs.

# Concepts

* [340B ID](/identifiers/provider/340b-id.md) - HRSA OPAIS covered-entity identifier.
* [AMA ME Number](/identifiers/provider/ama-me-number.md) - Medical Education number from the AMA Physician Masterfile (`ME_NUMBER` in Xponent).
* [CMS Certification Number](/identifiers/provider/ccn.md) - Medicare provider number for hospitals and facilities.
* [IQVIA DDD Outlet Number](/identifiers/provider/ddd-outlet.md) - IQVIA outlet key in DDD (`dddoutletnum`) with an outlet class/subcategory.
* [DEA Registration Number](/identifiers/provider/dea-number.md) - Registration per location for controlled substances; widely used as a ship-to identifier in 867 data (`CUST_DEA`, `HCO_DEA`).
* [HIN (HIBCC Health Industry Number)](/identifiers/provider/hin.md) - Location identifier used in contracts, chargebacks and 867 ship-to data (`CUST_HIN`).
* [IQVIA Prescriber ID](/identifiers/provider/ims-prescriber-id.md) - IQVIA's prescriber key in Xponent (`IMS_PRESCRIBER_ID`), mapped to NPI/ME#.
* [NCPDP Provider ID](/identifiers/provider/ncpdp-provider-id.md) - 7-digit pharmacy identifier (formerly NABP number).
* [National Provider Identifier (NPI)](/identifiers/provider/npi.md) - CMS-issued 10-digit ID; Type 1 = individual HCP, Type 2 = organisation.
* [NUCC Taxonomy Code](/identifiers/provider/nucc-taxonomy.md) - 10-character provider specialty code recorded in NPPES.
* [IQVIA OneKey ID](/identifiers/provider/onekey-id.md) - Identifier for HCPs/HCOs in IQVIA OneKey reference data.
* [Veeva Network VID](/identifiers/provider/veeva-vid.md) - Veeva OpenData/Network ID for HCPs (`HCP_VID`), HCOs (`ORG_VID`, `HCO_VID`) and systems (`SYS_VID`, `SYSTEM_VID`); commonly the master key for customer data in manufacturers' warehouses.
