# Payer Identifiers

BIN/PCN/Group, plan IDs.

# Concepts

* [BIN / PCN / Group](/identifiers/payer/bin-pcn-group.md) - Pharmacy-benefit routing triplet: BIN (processor), PCN (plan/line of business), Group (employer/benefit).
* [CMS Contract-PBP](/identifiers/payer/cms-contract-pbp.md) - Medicare Part D/MA contract and plan benefit package ID (e.g. H1234-001).
* [Payer Plan ID](/identifiers/payer/plan-id.md) - Vendor plan key (e.g. IQVIA `PAYER_PLAN_ID`, LAAD `PLAN_ID`) mapping to payer, PBM, model (commercial, Part D, Medicaid).
